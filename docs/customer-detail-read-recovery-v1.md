## 修复边界

- 只在 `getCustomerById` 的纯读取数据组装内应用 `withReadOnlyDbRetry`：主记录、地址、联系人、订单统计与 payload。
- 仅识别结构化 `error.code === 'P1017'`，不凭错误文本猜测；最多 3 次尝试，重试前分别等待 60 / 120 ms。其余错误直接向原 500 分支传播。
- 每次重试从带权限过滤的客户查找开始；找不到或范围改变仍返回 404，不泄露上一次部分数据。HTTP 响应只在读取完成后发送一次。
- 不修改通用 `withDbRetry`，不包装写操作，不重启/断开共享 Prisma 客户端。连接中断的写入可能已提交，本包不自动重放。
- 不宣称所有读接口都已支持故障恢复；目前仅客户详情 GET。
- 主备切换审计仍只发送一次创建 POST、一次跨实例 GET，不在测试端重试业务请求来掩盖 500。
- 审计详情 `httpStatus` 与判定 `status` 分离；详情不能覆盖检查名称及判定。报告版本 1.1。
