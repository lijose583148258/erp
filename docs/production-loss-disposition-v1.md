# 生产损耗、报废与返工处置（R2-07）

## 闭环边界

工单完工后，制造损耗不再允许通过通用调账或 `lossQuantity` 静默冲减。每一笔实际报废必须绑定：已完工工单、输出批次、实际扣减库位、数量、原因、不可复用幂等键和成本；返工只能从同一工单已过账的报废凭证回收，并生成新的 **隔离批次**，必须重新 QA 放行后才能领用。

`production_dispositions`、库存凭证、批次余额、库存成本台账及审计日志在同一事务内写入。相同幂等键仅允许逐字段一致的重放；不同业务事实返回冲突而不会重复扣减。

为阻止旧字段重新形成暗门：新建工单和完工中的非零 `lossQuantity` 都会被拒绝，提示通过受治理的批次处置登记。历史字段仅保留供既有凭证查询，不可作为新制造损耗的记账入口。
