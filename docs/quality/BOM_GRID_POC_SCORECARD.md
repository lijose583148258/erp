## 结论

两套候选均通过了代码接入和受控浏览器 PoC，但因 IME、网格内连续键盘操作、自定义物料编辑器三个一票否决项尚未通过，不能达到 85 分，也不能启用正式 `BOM_GRID_V2`。

RevoGrid 首轮实测暴露动态 `<style>` 被 `style-src-elem 'self'` 阻断。修复没有放宽为
`unsafe-inline`：服务端现在为每个响应生成密码学随机 CSP nonce，并向 HTML 注入匹配的
`csp-nonce` 元数据。修复后两候选浏览器控制台均为零错误，CSP、类型检查和正式构建通过。

全仓生产许可证门禁仍被既有依赖链阻断：

`exceljs@4.4.0 -> unzipper@0.10.14 -> binary@0.3.0 -> buffers@0.1.1`

其中 `buffers@0.1.1` 的锁文件许可证为 `Unknown`。候选网格自身没有该问题；不得通过降低许可证门禁绕过。

生产依赖 `npm audit` 也仍为红灯：根项目 10 个 high、后端 9 个 high，主要集中在既有
`exceljs`/压缩归档链；根项目另含 `gaxios` 链。原始 JSON 证据保存在
`artifacts/security/`。这些不是本次四个新增依赖引入，但在正式发布前仍必须升级、
替换或形成经过验证的隔离与风险接受记录。

## 下一轮人工验收

1. 在目标低配 Windows 上分别用微软拼音、越南语 Telex 输入法录入固定样本。
2. 在组合输入期间验证 Enter 不提前提交，Esc、Tab、方向键和连续 100 行输入不漂移。
3. 通过统一 Adapter 接入物料主数据选择器，再验证搜索、选中、清空和权限过滤。
4. 用同一操作员、同一机器、同一脚本重新评分；达到 85 分且所有否决项通过后才形成选型 ADR。
