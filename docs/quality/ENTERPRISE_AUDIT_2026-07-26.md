# 企业级增量审计报告（2026-07-26）

## 当前结论

本轮修复使生产 BOM 链、实验网格访问边界和生产汇总查询更可靠，但仓库仍不满足“无条件正式上线”。当前可用于隔离开发和受控内部试点；生产发布仍被依赖漏洞、真实 PostgreSQL 同窗迁移/回滚、物料主数据、Decimal、质量谱系及目标 Windows 人工 IME 验收阻断。

## 本轮已修复

1. **批次有效期不再静默写死 365 天**
   - BOM 新增 `shelfLifeDays`。
   - UI、Zod、OpenAPI 和服务层均要求 1–3650 的整数。
   - 完工事务在创建成品批次前再次校验，历史 BOM 未配置时失败关闭。
   - PostgreSQL 增量迁移含数据库 `CHECK` 约束。

2. **生产汇总不再全表加载**
   - 工单状态、产量和损耗改为数据库 `groupBy`/`aggregate`。
   - 最近工单固定只取 20 条。
   - 隔离 SQLite HTTP 100 次：p50 6.67 ms、p95 11.20 ms、p99 15.42 ms。

3. **BOM Grid Lab 不再开发环境自动开放**
   - 必须显式开启实验开关。
   - 仅管理员或实验用户白名单可进入。
   - 保存还要求 `production.write`；受限销售账号页面拒绝且 API 直写返回 403。

4. **RevoGrid CSP 兼容不以降低安全策略换取**
   - 首轮真实浏览器发现动态样式被 CSP 阻断。
   - 服务端改为每响应生成密码学随机 nonce，并向 HTML 注入匹配元数据。
   - 未给 `style-src-elem` 增加 `unsafe-inline`。
   - 修复后 RevoGrid 与 react-data-grid 浏览器控制台均为零错误。

5. **测试治理**
   - 删除 3 个已证实被替代或不安全的旧浏览器脚本。
   - 现有 273 个顶层脚本全部得到用途分类，没有未分类脚本。
   - 新增浏览器选择器门禁，防止依赖 DOM 索引的脆弱测试回流。

6. **Windows 实验运行器防止误杀进程**
   - 启动前拒绝占用端口，不接管其他程序。
   - PID 台账同时记录命令行、可执行文件和创建时间。
   - 停止前逐项核对身份，PID 被系统复用时失败关闭，不按旧 PID 盲目递归终止。

## 发布决定

**NO-GO：暂不能声明企业级正式上线。**

解锁正式发布至少需要同时满足：

1. 生产依赖漏洞与未知许可证门禁为绿；
2. 真实 PostgreSQL 导入、逐表/金额/库存/序列/外键核对、业务写入和 SQLite 回滚在同一发布窗口通过；
3. Decimal、物料主数据和历史 BOM 保质期迁移完成；
4. 财务/库存并发不变量、双实例 Redis/通知、备份恢复和告警送达使用目标拓扑复验；
5. 目标 Windows 上由真实操作员完成 IME、弱网、长会话和核心角色逐页验收。
