# 41_P0生产配方与工单字段级错误治理_20260618

## 目标

修复生产模块中 BOM / 配方版本、工单创建入口过度依赖 toast 的问题。此前用户保存失败时，关键字段本身缺少错误状态，按钮也只绑定全局 `loading`，无法区分“页面加载中”和“当前单据保存中”。

本轮只治理 P0 级可用性缺口，不扩展制造执行、排产、MES、APS 等大功能。

## 联网反幻觉校准

外部制造 ERP / BOM 资料和用户负反馈的共同点：

- BOM 错误不是孤立成本，会级联到物料成本、库存、生产返工、客户交付。
- 常见问题包括手工录入错误、重复部件、缺失小料、数量和单位错误。
- 制造型 ERP 用户经常抱怨工单、复杂工序、排产和 BOM 维护不好用，最后回退到表格。
- 因此当前阶段的合理 P0 不是立刻堆高级排产，而是先把配方和工单的关键输入错误明确暴露出来。

## 已执行改动

### 1. 公共生产输入框支持字段错误

文件：

- `pages/production/ProductionWorkspacePrimitives.tsx`

改动：

- `Field` 增加可选 `error` 参数。
- 有错误时自动增加 `aria-invalid`。
- 有 `dataTestId` 时自动绑定 `aria-describedby`。
- 错误显示在输入框下方。
- 既有调用不传 `error`，不改变现有页面。

### 2. BOM / 配方版本

文件：

- `pages/ProductionWorkspaceV2.tsx`
- `pages/production/ProductionBomSection.tsx`

改动：

- 新增 `BomFormErrors`。
- 产品名称为空时显示字段级错误。
- 输出单位为空时显示字段级错误。
- 百分比配方标准批量小于等于 0 时显示字段级错误。
- 百分比合计不为 100% 时在明细区显示错误。
- 有效物料为空、化工配方原料数量不足时在明细区显示错误。
- 保存期间禁用保存按钮并显示“保存中...”。
- 修改 BOM 明细时清除明细区错误，避免旧错误挂在页面上误导用户。

### 3. 工单创建

文件：

- `pages/ProductionWorkspaceV2.tsx`
- `pages/production/ProductionWorkOrderSection.tsx`

改动：

- 新增 `WorkOrderFormErrors`。
- 工单产品为空时显示字段级错误。
- 目标数量为空、非数字或小于等于 0 时显示字段级错误。
- 创建期间禁用按钮并显示“创建中...”。
- 目标数量只计算一次后传给后端，减少重复转换。

## 后续建议

下一步可以继续按优先级治理：

- P0：质检记录和生产批次异常调整的字段级错误、防重复提交。
- P1：BOM 明细重复物料 / 单位异常 / 百分比合计的行级提示。
- P2：工序步骤的最小可执行状态约束。
- P3：制造执行与库存扣料、质检、完工入库之间的回读证据链。
