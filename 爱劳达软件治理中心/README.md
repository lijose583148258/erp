# 爱劳达软件治理中心

## 目录

1. `01_总纲` - 系统治理总原则、范围边界和阶段判断。
2. `01_方案书原件` - 原始方案书与历史方案资料。
3. `02_对照表` - 已完成、进行中、待补全的对照表。
4. `03_系统核对` - 当前阶段判定、健康评估、角色权限、技术债务和深度审计资料。
5. `04_清理清单` - 建议归档、隔离和清理项。
6. `05_接入清单` - 建议重新接入和重启项。
7. `06_版本治理` - 版本分级和文档治理规则。
8. `07_部署落地` - 单机运行、离线运行、上线部署和迁移说明。
9. `08_代码结构梳理` - 代码目录结构、拆分原则和维护边界。
10. `09_偏航收口` - 当前偏航点、主线重排、功能分层结论。
11. `10_主线任务` - 主线任务总表、阶段推进清单、实点测证据和闭环执行记录。
12. `11_系统演变` - 从历史版本到当前版本的演变路径。
13. `12_扩展层` - 主线完成后的新增能力入口。
14. `13_CRM治理` - CRM、公海/私海、客户分配、权限和治理资料。
15. `99_隔离区` - 旧文件、坏文件、历史残留和待确认内容的隔离区。

## 当前结论

- 当前系统已经具备 ERP + CRM 主体雏形，核心链路包括客户、订单、回款、采购、仓储、生产、发货、货抵支付、审计和多语言。
- 当前仍处于“主线闭环继续收口”的阶段，不能只用编译通过判断可上线，必须以 API、数据库、浏览器实点测三层证据为准。
- 已建立默认制度：5 分钟运行上限、乱码三步法、禁乱码闸门、反幻觉验收、治理台账记录。
