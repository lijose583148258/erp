# 应急恢复手册

> 更新时间：2026-04-11  
> 读者：系统管理员、运维人员  
> 目标：数据库或服务器异常时，能在 10 分钟内恢复系统到可用状态

---

## 一、数据库文件位置

### 本地单机环境
```
C:\Users\<用户名>\AppData\Local\AilaoDaRuntime\stable.db
```
（也可能在 D:\AilaoDaRuntime\stable.db 或 %TEMP%\AilaoDaRuntime\stable.db，等级顺序见启动脚本）

### Docker 部署环境
```
Docker Volume: backend-data
实际路径：通过 docker volume inspect backend-data 查看 Mountpoint
```

### 备份文件位置
```
本地：f:\爱牢达\backend\backups\
Docker：Docker Volume: backend-backups
命名规则：stable.<YYYY-MM-DD>.db
```

## 二、常见问题排查

### 症状 1：启动后无法访问 http://127.0.0.1:5001

**排查步骤：**
```powershell
# 1. 检查端口是否被占用
netstat -ano | findstr :5001

# 2. 检查后端是否在运行
Get-Process -Name "node" -ErrorAction SilentlyContinue

# 3. 查看启动日志
Get-Content f:\爱牢达\backend\logs\stable-run.err.log -Tail 30
Get-Content f:\爱牢达\logs\combined.log -Tail 20
```

**解决：**
```powershell
# 重启服务
npm run start:stable
```

---

### 症状 2：登录成功但所有操作报 500

**可能原因：数据库只读**

```powershell
# 检查数据库文件属性
Get-Item "C:\Users\Administrator\AppData\Local\AilaoDaRuntime\stable.db" | Select Attributes

# 修复只读属性
attrib -r "C:\Users\Administrator\AppData\Local\AilaoDaRuntime\stable.db"
```

---

### 症状 3：数据库损坏或数据丢失

**从备份恢复：**
```powershell
# 1. 停止服务
npm run stop

# 2. 找到最近的备份文件
ls f:\爱牢达\backend\backups\ | Sort-Object LastWriteTime -Descending | Select-Object -First 5

# 3. 备份当前损坏的文件
$DBPath = "C:\Users\Administrator\AppData\Local\AilaoDaRuntime\stable.db"
Copy-Item $DBPath "$DBPath.broken.$(Get-Date -Format 'yyyyMMdd-HHmmss')"

# 4. 恢复备份
Copy-Item "f:\爱牢达\backend\backups\stable.2026-04-10.db" $DBPath

# 5. 重启服务
npm run start:stable
```

---

### 症状 4：Docker 容器启动失败

```bash
# 查看容器日志
docker logs ailao-backend --tail 50
docker logs ailao-web --tail 50

# 重建并重启
docker compose down
docker compose up --build -d

# 检查 volume 是否完好
docker volume ls | grep ailao
```

---

### 症状 5：CORS 问题（前端所有 API 返回 403/CORS Error）

**原因**：`docker-compose.yml` 中 `CORS_ORIGIN` 与实际访问域名不匹配。

```yaml
# docker-compose.yml 修改
CORS_ORIGIN: https://yourdomain.com,http://your-server-ip:8080
```

```bash
docker compose up -d  # 不需要 --build，仅重启即可
```

## 三、手动触发数据库备份

系统每 24 小时自动备份一次。如需立即备份：

```powershell
# 本地手动备份
$DB = "C:\Users\Administrator\AppData\Local\AilaoDaRuntime\stable.db"
$Backup = "f:\爱牢达\backend\backups\stable.manual.$(Get-Date -Format 'yyyyMMdd-HHmmss').db"
Copy-Item $DB $Backup
Write-Host "备份完成: $Backup"
```

## 四、外部 API (多国家货币) 异常

### 症状 6：汇率同步报错或显示使用“兜底汇率”
**排查步骤**：
```powershell
# 1. 检查服务器对中国银行及备用 API 的连通性
Test-NetConnection -ComputerName www.boc.cn -Port 443
Test-NetConnection -ComputerName open.er-api.com -Port 443
```
**应急方案**：
如果由于防火墙策略导致连通失败，系统将自动使用预设的兜底常量参数。管理员可通过修改代码或通知开发直接写入新的兜底汇率直至网络恢复。

## 五、恢复后验证

完成恢复后，访问以下路径验证系统正常：

| 检查项 | URL / 操作 |
|---|---|
| 服务健康 | `http://127.0.0.1:5001/health` → 返回 `{"status":"ok"}` |
| 前端页面 | `http://127.0.0.1:5001/` → 能看到登录界面 |
| 登录功能 | 输入 `admin / admin123` → 能进入仪表盘 |
| 数据读取 | 进入采购 → 看到供应商列表 → 确认有数据 |
| 写入功能 | 新建一条样品申请 → 确认保存成功 |
