## 1. 本地单机运行

### 推荐方式

```
双击 启动系统.bat
```

或命令行运行：

```bash
npm run start
# 等价于：powershell -ExecutionPolicy Bypass -File .\scripts\start-stable-v2.ps1
```

### 访问地址

| 服务 | 地址 |
|---|---|
| 系统入口（前端 + 后端合一） | `http://127.0.0.1:5001` |
| 健康检查 | `http://127.0.0.1:5001/health` |
| 默认账号 | `admin / admin123` |

### 单机特点

- 前端打包产物 (`dist/`) 由 Node.js 后端 Express 直接托管，**单端口** 访问。
- 数据库自动存放在 `C:\Users\<用户名>\AppData\Local\AilaoDaRuntime\stable.db`，**不在项目目录**，避免 git 污染。
- 启动脚本自动检测并复用 `dist/`，不重复构建，**冷启动约 2-5 秒**。
- 每日自动备份数据库，备份存放在 `backups/` 目录。

## 2. 服务器 Docker 部署

### 前置条件

- 服务器已安装 Docker 和 Docker Compose
- 已将项目代码传输至服务器

### 修改 CORS 配置（必须）

部署前须修改 `docker-compose.yml` 第 19 行：

```yaml
# 修改前（本地调试默认值）
CORS_ORIGIN: http://localhost:8080,http://127.0.0.1:8080

# 修改后（填写真实域名）
CORS_ORIGIN: https://yourdomain.com,http://your-server-ip:8080
```

> [!WARNING]
> 如果不修改此项，浏览器将因 CORS 拦截导致所有 API 请求失败，登录无法完成。

### 启动命令

```bash
docker compose up --build -d
```

### 访问地址

```
http://服务器IP:8080
```

### 容器架构

```
用户浏览器
    ↓ :8080
Nginx 容器 (ailao-web)
    ├── 静态文件 → /usr/share/nginx/html (前端 dist/)
    └── /api/ 请求 → 反向代理 → 后端容器 :5000
后端容器 (ailao-backend)
    └── SQLite 数据库 → Docker Volume 持久化
```

### Docker 持久化卷

| 卷名 | 内容 |
|---|---|
| `backend-data` | SQLite 数据库文件 |
| `backend-backups` | 自动备份文件 |
| `backend-logs` | 后端运行日志 |

## 3. 服务器直接部署（无 Docker）

如果服务器已有 Node.js 环境，可直接运行：

```bash
# 1. 安装依赖
npm install
npm --prefix backend install

# 2. 构建
npm run build
npm run build:backend

# 3. 设置环境变量并启动
NODE_ENV=production \
DATABASE_URL=file:/opt/ailao/data/stable.db \
SERVE_FRONTEND=true \
PORT=5001 \
CORS_ORIGIN=https://yourdomain.com \
node backend/dist/server.js
```

---

## 4. 环境变量说明

| 变量名 | 说明 | 示例值 |
|---|---|---|
| `NODE_ENV` | 运行环境 | `production` |
| `PORT` | 后端端口 | `5001` |
| `DATABASE_URL` | 数据库路径 | `file:/path/to/stable.db` |
| `SERVE_FRONTEND` | 是否托管前端静态文件 | `true` |
| `CORS_ORIGIN` | 允许跨域的来源 | `https://yourdomain.com` |
| `JWT_SECRET` | JWT 签名密钥（生产必填强密钥） | `your-random-secret` |
| `BACKUP_DIR` | 备份目录 | `/app/backups` |
| `LOG_DIR` | 日志目录 | `/app/logs` |

---

## 5. 升级到 PostgreSQL

当前使用 SQLite，适合单机和中小规模部署。  
如需升级到 PostgreSQL（多并发、多节点），运行：

```bash
npm run db:pg
```

并将 `DATABASE_URL` 改为 PostgreSQL 连接字符串。
