# 单机与线上部署说明

## 1. 单机使用

### 推荐方式

- 直接双击 [启动系统.bat](/F:/爱牢达/启动系统.bat)
- 前端地址：`http://localhost:3002`
- 后端地址：`http://localhost:5001`

### 单机特点

- 使用本地 SQLite 数据库
- 数据库文件默认放在 `backend/prisma/dev.db`
- 备份文件默认放在 `backend/backups`
- 日志默认放在 `backend/logs`

## 2. 线上部署

### 推荐方式

- 进入仓库根目录执行 `docker compose up --build -d`
- 前端地址：`http://服务器IP:8080`
- 后端由前端容器通过 Nginx 反向代理到 `backend:5000`

### 线上特点

- 前端静态资源由 Nginx 托管
- 后端独立容器运行
- SQLite 数据文件用 Docker volume 持久化
- 备份目录和日志目录也用 volume 持久化

## 3. 环境文件

### 本机开发

- [backend/.env.example](/F:/爱牢达/backend/.env.example)
- [.env.production.example](/F:/爱牢达/.env.production.example)

### 关键项

- `PORT`
- `DATABASE_URL`
- `CORS_ORIGIN`
- `BACKUP_DIR`
- `LOG_DIR`
- `SERVE_FRONTEND`

## 4. 当前建议

先保持 SQLite 方案跑通单机和 Docker 线上部署，等业务稳定后，再考虑把数据库底座切到 PostgreSQL。
