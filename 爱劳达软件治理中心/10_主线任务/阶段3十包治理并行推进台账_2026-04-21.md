# 阶段 3 十包治理并行推进台账 2026-04-21

## 1. 总目标

目标不是“某次测试全绿”，而是推进到：

1. 本地单机可稳定运行两个月。
2. 运行证据可持续累计。
3. 后续迁移服务器时不需要重做业务逻辑。
4. 旧入口、旧脚本、旧数据和当前有效链路边界清楚。
5. 所有关键模块都有小闭环证据，最后汇总为大闭环证据。

固定制度：

1. 5 分钟运行上限，超过必须判定卡住。
2. 乱码三步法默认开启：先翻译、再判断层级、再修复。
3. 禁乱码闸门默认开启。
4. 反幻觉验收默认开启：build-only 不等于完成。
5. 不删除用户数据、历史资料、备份包和数据库。
6. 稳定入口固定为 `http://127.0.0.1:5001/`。

## 5. 总体验收链

任何包合入前，至少需要按影响范围跑：

1. `npx tsc --noEmit`
2. `npm run build`
3. `npm --prefix backend run build`
4. `npm run lint`
5. `node .\scripts\effective-source-mojibake-gate-v1.cjs`
6. `npm run start:stable`
7. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-runtime.ps1`
8. `npm run verify:phase3:browser`
9. `npm run verify:release:core`

如果包只改文档，可以不跑全部命令，但必须说明原因。
