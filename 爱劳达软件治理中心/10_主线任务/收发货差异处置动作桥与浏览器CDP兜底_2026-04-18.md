# 收发货差异处置动作桥与浏览器 CDP 兜底

日期：2026-04-18

## 本包目标

本包不是再做一个新页面，而是把“收发货差异工作台”从只会评审/关闭，推进到能发起后续业务动作，并补上浏览器验收层的 CDP 连接兜底。

核心目标：

1. 差异单可以生成可追溯的处置动作记录。
2. 客户少收、拒收、损坏等场景可以从差异单转成客户 RMA。
3. API 验收必须包含写入、读回、目标单据读回、差异单回读，不允许只看 HTTP 200。
4. 浏览器自动启动被 `spawn EPERM` 阻断时，报告必须明确写成环境阻塞，而不是误报业务失败或假装通过。

## 本包已完成

### 后端

- 新增 `ReceiptDiscrepancyAction` 数据模型，用于记录差异单后续动作。
- 运行库修复脚本补齐 `receipt_discrepancy_actions` 表和索引。
- 新增差异动作 API：
  - `GET /api/receipt-discrepancies/:id/actions`
  - `POST /api/receipt-discrepancies/:id/actions`
- `customer_rma` 动作已形成闭环：
  - 校验差异单为客户侧。
  - 校验客户存在且有效。
  - 创建 RMA。
  - 创建差异动作记录。
  - 更新差异单 `actionRef` 和状态。
  - 记录审计日志。
- 已补客户 RMA 动作幂等保护：同一差异单、同一动作类型、未取消状态下重复提交，只返回已有动作，不再生成第二张 RMA。

### 前端

- `ReceiptDiscrepancyWorkbench` 增加轻量动作入口：
  - 客户侧差异可快速转 RMA。
  - 未关闭差异可创建待财务处理动作。
  - 保留原来的评审和关闭动作。
- 差异队列补充“处置动作”列，已接后续动作的差异单会显示动作号。
- 已接后续动作的差异单不再显示可重复发起的转 RMA/待财务操作，避免用户误以为按钮没生效。
- 本包只做最小 UI 动作入口，不把复杂处理抽屉一次性塞入页面，避免补丁式失控。

### 验收脚本

- 新增 `scripts/receipt-discrepancy-action-api-audit-v1.cjs`。
- 新增 `scripts/lib/browser-connect-or-launch.cjs`。
- 新增 `scripts/browser-cdp-probe.cjs`。
- `receipt-discrepancy-workbench-browser-audit-v1.cjs` 已改成优先 CDP 连接，再回落启动浏览器。
- 浏览器被环境阻断时，报告状态改为 `blocked_env`，并写入 `PLAYWRIGHT_SPAWN_EPERM`。

## 浏览器验收状态

当前可以声明“收发货差异工作台”这一页的浏览器点测通过，但不能扩展成“全系统浏览器点测通过”。

本轮先遇到一个真实卡住点：

```text
CDP 探针连接成功，但 Node 进程没有退出，超过 5 分钟应判定为卡住。
```

修复：

1. 新增 `scripts/start-cdp-browser.ps1`，用于打开验收专用 Edge CDP 浏览器。
2. `BROWSER_CDP_REQUIRED=1` 时，如果没有 `BROWSER_CDP_URL`，直接报 `BROWSER_CDP_URL_MISSING`，不再回落到 Playwright 自动启动。
3. `browser-cdp-probe.cjs` 增加 30 秒脚本级 watchdog，成功后主动 `process.exit(0)`。
4. `receipt-discrepancy-workbench-browser-audit-v1.cjs` 增加 90 秒脚本级 watchdog，浏览器关闭也加 5 秒保护。
5. 清理浏览器审计脚本中的旧乱码常量，改用 Unicode code point 生成坏字检测模式。
6. 刷新读回规则时，先用规则搜索框按新规则名检索，再判断是否显示，避免分页/排序导致误判。

## 方向反思

本包没有偏离主线。

原因：

- 没有继续堆新模块，而是把已有“差异工作台”接到真实 RMA 链路。
- 没有假装浏览器通过，而是把环境阻塞分类为可追踪问题。
- 没有为了 UI 漂亮大改页面，只补最小动作入口。
- 没有删除旧文件或用户数据。

需要警惕：

- 如果下一步继续只做 API，不解决浏览器证据，就会再次产生“后台绿、前台不一定能用”的幻觉。
- 如果一次性把质检、供应商退货、财务、库存全塞进同一个页面，会让工作台变成新的屎山。
- 差异动作必须逐个接真实目标单据，不能只做一个 `actionType` 字段就宣称闭环。
