# 化工配方主档与 BOM 职责正名调研收口

日期：2026-04-25

## 本轮结论

本轮没有继续扩大功能，而是把生产模块里容易让用户迷路的命名和职责先拉正。

对于爱劳达当前的胶水、树脂、涂料业务，更合适的表达不是把所有内容都叫“BOM 管理 / BOM 明细”，而是：

- 配方主档：产品或配方对象的主数据入口。
- 配方版本：某一版可审批、可生效、可回读的生产依据。
- 原料明细：跟随配方版本保存的行项目，不单独生成业务结果。
- 工单实际耗用：生产执行时确认真实消耗、损耗、质检、入库。
- 仓储释放/领料：根据工单或批次将原料从仓库释放到生产现场。

## 调研依据

- Microsoft Dynamics 365 Supply Chain 将过程制造中的物料结构称为 Formula / Formula version，并区分 formula lines、版本审批、生效范围、可伸缩用量和阶梯用量。
  来源：[Formulas and formula versions](https://learn.microsoft.com/en-us/dynamics365/supply-chain/production-control/formulas-versions)
- Microsoft Dynamics 365 还把 BOM/formula lines 到仓库释放作为生产/批次订单释放后的独立步骤，说明“配方主数据”和“生产领料/实际耗用”不应该混在一个输入区域。
  来源：[Release BOM and formula lines to the warehouse](https://learn.microsoft.com/en-us/dynamics365/supply-chain/production-control/releasing-bom-and-formula-lines-to-warehouse)
- MRPeasy 将 BOM 区域作为列表、增改、CSV 导入导出、批量替换和报表入口，强调它是生产计划下的基础资料清单，不是工单实际耗用记录。
  来源：[MRPeasy Bills of Materials](https://www.mrpeasy.com/resources/user-manual/production-planning/bills-of-materials/)
- 金蝶 K3 Cloud 公开帮助中，生产用料清单由生产订单和 BOM 子项带出，BOM 版本参与展开逻辑，说明成熟国产 ERP 也会区分基础 BOM、生产订单、用料清单。
  来源：[金蝶 K3 Cloud 生产用料清单](https://open.kingdee.com/K3Cloud/help/PRD_PPBOM.html)

## 本轮反思

之前的风险点不是“配方方向错”，而是三个层面容易脱钩：

- UI 已经正名为“配方版本”，但浏览器验收脚本还在找旧按钮“保存 BOM”。
- 并行跑审计时，某些审计脚本会短暂重启或检查运行态，导致人工流撞上 `127.0.0.1:5001` 连接拒绝。
- PowerShell `Get-Content` 对中文报告显示会出现乱码，但 Node 以 UTF-8 读取 JSON 时标题正常，这属于终端显示层，不是源码层。

后续固定规则：

- 业务文案改名后，必须同步更新浏览器审计夹具，不允许 UI 绿、脚本旧。
- 人工流审计不要和会重启运行态的审计并行跑；可以并行静态检查、来源检查、包新鲜度检查。
- 遇到乱码必须先做三步法：翻译意图、判断层级、只修正确层，不直接重写文件。

## 本轮改动

- `pages/production/ProductionBomSection.tsx`：将生产基础资料入口正名为“配方主档工作台”，明确左侧主数据、右侧原料明细、下方已保存版本回读。
- `pages/ProductionWorkspaceV2.tsx`：将模块页签从“配方 / BOM”收束为“配方主档”，避免和工单实际耗用抢职责。
- `scripts/lib/production-browser-audit-fixtures.cjs`：将生产浏览器审计按钮目标从“保存 BOM”改为“保存配方版本”。
- `scripts/cdp-core-pages-smoke-audit-v1.cjs`：同步核心页面冒烟期望文案。
- `scripts/lib/browser-human-flow-production-module.cjs`：将人工流生产路由检查从旧的“BOM”改为“配方主档 / 工单”。
- `scripts/lib/browser-human-flow-modules.cjs`：将生产人工流说明从 chemical BOM 改为 chemical formula lines。
