## 当前发现的问题

### A. 订单工作台假失败
- 页面提示：`订单工作台加载失败`
- 实际情况：
  - `/api/orders?pageSize=100` 返回 200
  - `/api/customers?pageSize=1000` 返回 200
  - `/api/assets/batches` 返回 200
- 判断：
  - 不是后端整体失败
  - 更像前端初始化链被某一路失败拖累，错误状态未清空

### B. 订单新增弹层客户下拉为空
- 现象：
  - “录入新销售单”弹层能打开
  - 客户下拉只有“选择客户...”
- 风险：
  - 无法继续完成人工订单新增
- 初步判断：
  - 订单页初始化使用 `Promise.all`
  - 某一路（合同链）失败会导致订单和客户列表都不写入页面状态

### C. 订单页初始化修复后复测结果
- 操作：
  - 重新进入“销售订单”
  - 打开“录入新销售单”
  - 检查客户下拉
- 结果：通过
- 说明：
  - 客户下拉已加载真实选项
  - 已确认包含：
    - `UI Smoke Customer 0524`
    - `Smoke CN 222028`
    - `广州材料科技`
    - `上海贸易公司`
    - `浙江化工集团`
- 修复依据：
  - `contract.service.ts` 增加 `getContracts`
  - `useSalesOrders.ts` 将工作台初始化改为 `Promise.allSettled`

### D. 订单人工新增最短链
- 操作：
  - 在“录入新销售单”中选择客户 `浙江化工集团`
  - 输入产品 `UI Smoke Order 0524`
  - 输入单价 `100`
  - 点击“保存更改”
- 结果：通过
- 说明：
  - 页面保存后订单列表从 `1` 条变为 `2` 条
  - 后端真实回读确认新订单已落库：
    - `orderNo = ORD-1775800213514`
    - `customerId = 1`
    - `customerName = 浙江化工集团`
    - `totalAmount = 100`
  - 说明订单人工输入这条链已经不丢数据

### E. 新订单列表客户列瞬时空白
- 现象：
  - 刚创建成功后，订单列表中新订单的“往来单位”列显示为空
  - 但 API 回读显示客户字段完整
- 判断：
  - 不是数据丢失
  - 是前端创建后回填列表时字段映射问题
- 根因：
  - `useSalesOrders.ts` 保存时用 `c.id === formData.customerId`
  - 一个是数字，一个是字符串，导致新建后回填客户名失败
- 已修复：
  - 将 `customerId` 正规化为数字后再查找客户
  - 新建后列表更新改为 `setOrders(prev => [savedOrder, ...prev])`
- 状态：
  - 代码已修复
  - UI 刷新后需再做一次视觉复核

### F. 页面刷新后回到首页
- 现象：
  - 刷新后不保留当前业务页，会回到首页
- 判断：
  - 这是前端状态持久化问题
  - 不是订单数据丢失
- 风险：
  - 会干扰人工点测效率
  - 也会让用户误以为当前页失效
- 后续方向：
  - 单独排查 activeTab / 路由 / 本地状态持久化
