# 包5：部署稳定性与上线验收

## 包目标
把系统收口到单机可用、Docker 可部署、线上可接入、备份可恢复、状态可查询、日志可追踪。

## 当前成果
- Docker 镜像链路已完成
- docker compose 已完成
- Nginx 反向代理已完成
- 健康检查接口已完成
- 系统状态接口已完成
- 日志目录与备份目录已完成
- 备份与恢复演练已完成

## 当前验收口径
- 单机模式可直接启动
- Docker 模式可独立运行
- 线上模式可通过 Nginx 反代接入
- 数据库备份可生成
- 数据库恢复可执行
- `/health` 与 `/api/system/status` 可查询

## 验证结果
- `npm run build` 通过
- `npm run build:backend` 通过
- `npm run db:manage -- status` 通过
- `npm run db:manage -- backup` 通过
- `npm run db:manage -- restore <backup-file.db>` 通过

## 后续维护建议
- 继续保留 Docker 与单机双入口
- 备份目录和日志目录保持独立挂载
- 上线前固定一次备份与恢复演练
- 对外只保留健康检查与状态查询，不开放多余运维入口
