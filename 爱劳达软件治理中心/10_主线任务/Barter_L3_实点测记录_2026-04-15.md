## 验收步骤

1. 登录态注入。
2. 打开 Barter 页面。
3. 浏览器真实填写客户、对手方、结算模式、币种、备注、双方货物明细。
4. 点击创建货抵结算单。
5. 列表可见新单据。
6. API 搜索回读新单据。
7. API 审批货抵单。
8. API 过账货抵单。
9. API 详情回读单据、明细、估值快照、抵扣过账记录。
