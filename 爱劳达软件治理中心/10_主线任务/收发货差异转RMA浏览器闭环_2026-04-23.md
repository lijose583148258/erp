# 收发货差异转 RMA 浏览器闭环

- 日期：2026-04-23
- 范围：收发货差异工作台、处置动作、RMA 生成与回读、Phase 3 验收链
- 入口：`http://127.0.0.1:5001/#discrepancies`

## 本包目标

把“客户签收短少/破损/错货”这类差异，从工作台上的“转 RMA”按钮落实为真实业务闭环：

1. 差异单必须来自真实发货签收差异。
2. 页面按钮必须能触发后端 `customer_rma` 处置动作。
3. 后端必须生成真实 `rmas` 单据。
4. 差异动作必须记录 `targetModule=rma`、`targetId`、`targetRef`。
5. 差异单必须进入 `in_review`，并显示 actionRef，避免重复点击生成第二张 RMA。
6. API 回读和浏览器回读都必须通过，不能只看构建通过。
