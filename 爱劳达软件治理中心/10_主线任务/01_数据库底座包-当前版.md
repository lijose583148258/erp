# 01：数据库底座（当前版）

## 包目标
统一数据库运行入口，保证系统既能单机使用，也能为后续 PostgreSQL 迁移保留平滑边界。

## 当前成果
- 数据库主入口统一到 `db:manage`
- 备份、恢复、状态查询已经统一
- seed 已改成幂等写法
- SQLite 单机路线已打通
- Docker 与部署路线已支持持久化
- PostgreSQL 迁移计划已明确
- PostgreSQL 迁移快照导出脚本已补齐
- PostgreSQL 回滚脚本已补齐

## 验证结果
- `npm run build:backend` 通过
- `npm run db:pg -- plan` 通过
- `npm run db:pg -- snapshot` 通过
- `npm run db:pg -- rollback <backup-file.db>` 通过

## 当前状态
- 当前运行底座仍然是 SQLite
- 迁移准备能力已经建立
- 未来切换 PostgreSQL 不再需要重新梳理数据边界

## 下一步
- 如后续决定切换 PostgreSQL，仅需按迁移计划执行
- 当前不再追加新的数据库入口
