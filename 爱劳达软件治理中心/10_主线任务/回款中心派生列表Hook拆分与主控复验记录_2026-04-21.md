# 回款中心派生列表 Hook 拆分与主控复验记录

## 范围

- 修改：`pages/collections/useCollectionCenter.ts`
- 新增：`pages/collections/useCollectionCenterDerivedLists.ts`

## 为什么做

`useCollectionCenter.ts` 同时承载加载、权限、动作、筛选、排序和返回状态，维护时容易把“业务动作”和“只读派生列表”混在一起。  
本包只拆出筛选与排序，降低后续修改回款页面时误碰写入链路的概率。

## 本包边界

- 不改 API。
- 不改权限判断。
- 不改回款核销、催收提醒、承诺付款、争议处理、拦截释放动作。
- 不改 UI 样式和布局。
- 只移动 `filtered*` 和 `sorted*` 派生列表逻辑。

## 结构变化

- `useCollectionCenter.ts`：保留数据加载、权限、动作函数、选中订单状态和返回对象。
- `useCollectionCenterDerivedLists.ts`：集中维护逾期、承诺、争议、拦截、台账、里程碑的筛选与排序。

## 乱码三步法

本包没有改中文文案。  
如果 PowerShell 再次显示 `鍥炴...`，必须先用 Node UTF-8 读取源码确认真实内容，不能直接重写。
