# 桌面 EXE 壳 P0 收口记录

## 结论

当前已经完成 P0 桌面壳：

- 产物：`AilaoDa_Stable_Package/AilaoDa-ERP-CRM.exe`
- 类型：Windows WinForms 轻量桌面壳
- 入口：`http://127.0.0.1:5001/`
- 运行库：`D:/AilaoDaRuntime/stable.db`

它是“本地稳定包启动壳”，不是完整安装器。  
后续如果要做安装器、自动升级、桌面快捷方式、开始菜单注册、WebView 内嵌窗口，需要作为 P1/P2 单独推进。

## 为什么这样做

- 不引入 Electron/Tauri，避免新增大运行时和新的打包复杂度。
- 不改变前后端业务代码。
- 不复制第二套数据库。
- 不触碰旧包、历史数据、用户上传文件。
- 只调用稳定包内的启动、停止、健康检查脚本。

## 壳能力

- 双击打开桌面控制台。
- 一键启动系统。
- 一键打开工作台。
- 一键健康检查。
- 一键安全停止。
- CLI 支持：
  - `--print-config`
  - `--start`
  - `--health`
  - `--stop`
  - `--open`

## 纳入治理链

- `npm run build:desktop-shell`
- `npm run audit:desktop-shell`
- `npm run audit:daily:local-governance`

`package-stable.ps1` 已纳入桌面壳构建，后续重新打稳定包时不会丢失 EXE。

## 边界

- 当前 EXE 默认打开系统入口，不内嵌 WebView。
- 当前 EXE 不做安装路径管理。
- 当前 EXE 不做自动更新。
- 当前 EXE 不负责数据迁移。
- 当前 EXE 不应被放到旧包或其他项目目录中运行。
