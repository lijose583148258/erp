# 数据字典（当前版）

> 更新时间：2026-04-11  
> 说明：记录系统核心数据模型的字段语义、取值枚举和业务规则，避免跨模块维护歧义。

---

## 客户（Customer）

| 字段 | 类型 | 业务含义 | 取值规则 |
|---|---|---|---|
| `name` | String | 主要名称（内部标识） | 必填，从 nameZh/nameEn/nameVi 中取第一个有效值 |
| `nameZh` | String? | 中文名 | 中国/国内客户首选 |
| `nameEn` | String? | 英文名 | 国际客户首选 |
| `nameVi` | String? | 越南文名 | 越南方向客户首选 |
| `nameAliases` | String? | 别名列表 | JSON数组序列化存储，如 `["别称A","旧名B"]` |
| `poolState` | Enum | 客户池归属状态 | `public`（公海）/ `internal`（内部公池）/ `private`（私海） |
| `segment` | Enum | 客户分层 | `direct`（直客）/ `channel`（渠道商）/ `mixed`（混合） |
| `riskLevel` | Enum | 风险等级 | `low` / `medium` / `high` |
| `overdueAmount` | Decimal | 逾期欠款金额 | **目前为手录字段**，非自动计算，未来需联动回款自动更新 |
| `creditLimit` | Decimal? | 授信额度 | 控制下单上限，由 CreditEngine 校验 |
| `creditHold` | Boolean | 是否信用冻结 | true 时禁止新建订单 |
| `shipmentHold` | Boolean | 是否发货冻结 | true 时禁止状态流转到 shipped |
| `dunningLevel` | Int | 催款等级 | 0=正常, 1=初催, 2=二次催, 3=法务介入（目前手动维护） |
| `collectionsStatus` | String | 催收状态 | `normal` / `overdue` / `written_off` |

## 订单（Order）

| 字段 | 类型 | 业务含义 | 取值规则 |
|---|---|---|---|
| `orderNo` | String | 订单号 | 系统自动生成，格式 `ORD-{timestamp}` |
| `status` | Enum | 订单状态 | `pending` → `confirmed` → `shipped` → `delivered` → `cancelled` |
| `totalAmount` | Decimal | 原始总金额（含折扣前） | 由 items 汇总自动计算 |
| `discountAmount` | Decimal | 折扣金额 | 手动输入 |
| `finalAmount` | Decimal | 实际应收金额 | `totalAmount - discountAmount` |
| `currency` | String | 交易币种 | 默认 `CNY`，支持 `USD`, `VND`, `EUR`, `HKD` |
| `lockedExchangeRate` | Decimal? | 锁定汇率 | 下单时锁定的对人民币汇率快照 |
| `baseAmount` | Decimal? | 本位币金额 | 以 CNY 计价的等值金额 |
| `paidAmount` | Decimal | 已收款金额 | 由 PaymentRecord 审核后自动累加 |
| `paymentTerms` | Int | 账期天数 | 默认 30 天，影响逾期判断 |
| `contractId` | Int? | 关联合同 | 可选，关联后付款可触发里程碑 |

## 客户池状态（poolState）说明

```
public（公海）
  └── 所有 manager 和 sales 可见
  └── 任何 sales 可抢入私海

internal（内部公池）  
  └── 全公司可见
  └── 需要 manager 分配给 sales

private（私海）
  └── 仅归属 sales 和 manager 可见
  └── sales 不能自行调整归属
  └── 限期内无进展会被系统（目前为手动）回公海
```

## 付款记录（PaymentRecord）

| 字段 | 类型 | 业务含义 | 备注 |
|---|---|---|---|
| `amount` | Decimal | 交易金额（原币） | 客户实际按交易币种支付的金额 |
| `currency` | String | 交易币种 | 默认 `CNY` |
| `exchangeRate` | Decimal | 执行汇率 | `1 CNY = X 外币` |
| `baseAmount` | Decimal | 本位币金额 | 换算为 CNY 的金额，按系统快照或人工校准汇率 |
| `status` | Enum | 审核状态 | `pending` → `verified`（finance/manager 审核后才计入 paidAmount） |
| `isProxy` | Boolean | 是否代收 | true 表示通过第三方收款 |
| `method` | String | 付款方式 | `cash` / `transfer` / `barter`（货抵） / `pos` 等 |
| `milestoneId` | Int? | 关联合同里程碑 | 付款后触发对应里程碑完成 |
| `barterItemId` | Int? | 货抵支付关联货物 | 货抵场景使用，关联 BarterItem |

## 货抵支付（BarterWorkspace）

| 字段 | 类型 | 业务含义 | 备注 |
|---|---|---|---|
| `offsetType` | Enum | 货抵类型 | `goods`（货物冲账）/ `advance`（预付款抵扣） |
| `postingAmount` | Decimal | 冲账金额 | 货物折算的金额 |
| `status` | Enum | 结算状态 | `pending` / `settled` / `disputed` |

## 资产移动（AssetMovement）

| type 值 | 含义 |
|---|---|
| `dispatch` | 发出资产（如发出包装桶/托盘给客户） |
| `return` | 客户归还资产 |
| `lost` | 资产丢失确认 |
| `adjust` | 手动盘点调整 |

## 系统级别

| 字段 | 类型 | 说明 |
|---|---|---|
| `createdBy` | Int | 创建人 userId（非 username） |
| `resourceId` | Int? | 审计日志关联的业务记录 ID |

## ⚠️ 需要注意的歧义字段

| 字段 | 歧义点 |
|---|---|
| `Customer.overdueAmount` | 目前手动录入，非由系统计算生成，可能与实际回款不一致 |
| `Customer.dunningLevel` | 系统无自动升级逻辑，依靠人工维护 |
| `Order.paidAmount` | 仅在 `PaymentRecord.status = verified` 时才更新，pending 状态收款不计入 |
| `Customer.name` | 实际上是"内部主标识符"，不一定是对外名称，对外显示应优先用 nameZh/nameEn/nameVi |
