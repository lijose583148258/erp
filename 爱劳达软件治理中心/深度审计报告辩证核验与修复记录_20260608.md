# 深度审计报告辩证核验与修复记录

生成时间：2026-06-08

来源文件：`爱劳达系统深度审计报告.md`

## 判定原则

不把外部审计报告当成最终事实。每一项必须回到当前源码、运行包、审计脚本核验后再处理。

## 本轮确认成立并已修复

1. Service Worker / PWA 策略矛盾  
   报告指出系统一边声明 PWA，一边每次加载主动注销 Service Worker。该问题成立。当前产品定位是本地/服务器业务系统，不走离线 PWA 路线。  
   修复：`index.html` 移除 PWA manifest、移动 Web App meta、Service Worker 注销逻辑、安装提示逻辑。避免 Chromium 竞态和错误安装预期。

2. `/health` 暴露磁盘字节信息  
   报告指出未认证健康检查暴露 `freeDiskBytes` 与 `minimumFreeDiskBytes`。该问题成立。  
   修复：`/health` 和 `/api/health` 只返回状态、模式、检查项结果，不再返回磁盘容量字节。详细磁盘信息迁移到 `/api/system/health-details`，并要求 `admin` 认证。

3. JWT 生产密钥占位符风险  
   报告指出生产环境不能允许占位符密钥。当前已有“生产环境必须设置 JWT_SECRET”的基础校验，但未拦截 `replace_with`、`your-secret`、`changeme` 等弱占位符。  
   修复：`backend/src/utils/jwt.ts` 增加生产密钥强校验，长度至少 32，且不得包含常见占位符。

4. SQLite WAL 配置需要明确证据  
   报告认为 WAL 未启用。当前源码已存在 `PRAGMA journal_mode = WAL`、`busy_timeout`、`foreign_keys`，所以报告对“未启用 WAL”的判断已过期。  
   增强：补齐 `synchronous = NORMAL` 和 `cache_size = -64000`，降低本地 SQLite 写入阻塞风险。

## 本轮确认已存在，不重复修

1. 路由级错误边界  
   当前 `app/appContent.tsx` 已用 `PageErrorBoundary` 包裹每个懒加载页面。该项不是缺失项。

2. 构建前清理 dist  
   当前 `npm run build` 先执行 `scripts/clean-dist-v1.ps1`，再执行 Vite build。报告中“三倍冗余构建产物”的风险已被构建流程治理覆盖。

3. 触屏操作和表格长文本  
   当前已在 `index.css`、`DataTable`、`EnterpriseDataGrid` 中治理触屏操作显示、长文本截断和完整 title。

## 暂不在本轮硬改

1. Product Master  
   这是数据模型重构，不是小修。需要迁移设计、历史快照、库存/订单/生产/采购链路回读，不能直接替换 `productName`。

2. OrderItem 多货币字段  
   需要数据库迁移、历史数据回填、报表口径确认。本轮不做局部字段堆叠。

3. Customer 联系人/地址双轨迁移  
   需要迁移脚本和 UI 读写口径统一。本轮不直接删旧字段。

4. DataTable 与 EnterpriseDataGrid 合并  
   当前更适合逐步收敛到统一适配层，不做大拆大换。

5. 未保存变更提醒  
   需要统一表单 dirty 状态协议。当前各模块表单实现差异较大，不能通过全局 `beforeunload` 粗暴解决，否则会误拦截列表筛选、搜索、临时弹窗。
