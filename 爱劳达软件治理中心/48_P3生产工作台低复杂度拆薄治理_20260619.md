# 48_P3生产工作台低复杂度拆薄治理_20260619

## 范围

- `pages/ProductionWorkspaceV2.tsx`
- `pages/production/ProductionWorkspaceDerived.ts`
- `pages/production/useProductionUnsavedFormGuards.ts`
- `pages/production/ProductionWorkspaceModals.tsx`
- `pages/production/ProductionWorkspaceShellHeader.tsx`

## 问题

全仓审计将 `pages/ProductionWorkspaceV2.tsx` 列为 P2 超大运行时文件。该文件原本同时承担：

- 页面状态和业务提交动作。
- BOM 过滤、统计卡、批次追踪轨迹等派生数据。
- 未保存表单保护的四组快照配置。
- 顶部标题、统计卡、工作区导航和底部弹窗拼装。

这些内容混在主文件里，后续维护时容易误碰生产、质检、批次调账等高风险流程。

## 处理原则

- 不改 API，不改业务状态机，不改提交流程。
- 只抽无副作用计算、页面壳层和弹窗出口。
- 新文件保持短小，避免为了拆分制造新的复杂层。

## 已完成

- 新增 `ProductionWorkspaceDerived.ts`：承接 BOM 过滤、统计卡、批次轨迹、导航计数、BOM 明细 payload、工序 payload。
- 新增 `useProductionUnsavedFormGuards.ts`：承接生产 BOM、工单、质检、批次调整四组未保存保护。
- 新增 `ProductionWorkspaceModals.tsx`：承接完工扣料弹窗和调账冲销弹窗。
- 新增 `ProductionWorkspaceShellHeader.tsx`：承接生产标题区、统计卡和工作区导航。
- `ProductionWorkspaceV2.tsx` 从 720 行降到 599 行，不再进入全仓 P2 超大文件清单。
