## 发现的问题

### P0 发布治理阻塞：源码工作区未冻结

工作区有 410 条变更，其中 181 条未跟踪。即使当前 zip 可运行，也很难证明它和某个干净源码版本一一对应。

处理建议：

1. 建立发布候选分支或快照。
2. 把本轮前端治理 4 个文件和必要发布脚本分组提交。
3. 历史大批变更按模块拆分归档，不要混入下一个包。
4. 生成 `SOURCE_MANIFEST`，记录 zip 哈希、commit、dist asset hash、backend build time。

### P1 审计脚本路径脆弱

`scripts/shipping-receipt-concurrency-audit-v1.cjs` 在加载 Prisma 后会受到本地 `.env` 的 `DATABASE_URL=file:./runtime-data/stable.db` 影响，导致直连错误路径并报：

`Error code 14: Unable to open the database file`

显式设置：

`DATABASE_URL=file:D:/AilaoDaRuntime/stable.db`

后审计通过。

处理建议：审计脚本应优先读取运行时 origin 报告或强制使用 `D:/AilaoDaRuntime/stable.db`，不要被开发态 `.env` 影响。

### P1 审计并行会制造假失败

备份恢复和数据库直连并发执行时，曾出现：

`EBUSY: resource busy or locked, copyfile 'D:\AilaoDaRuntime\stable.db-shm'`

顺序单独执行后备份恢复通过。

处理建议：发布验证脚本需要给备份恢复、数据库直连类审计加互斥/顺序执行规则。

### P2 报告层中文显示仍有乱码

部分 JSON 报告在控制台或文件中出现中文 mojibake。业务接口编码审计通过，但报告可读性较差。

处理建议：统一审计脚本输出编码，避免后续人工复盘误判。
