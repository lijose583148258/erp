# 34_P0表格列显示与分页记忆治理_20260617

## 治理结论

本轮继续执行 P0 公共可用性底座，不新增复杂业务功能，只修复高频 ERP 表格在真实使用中的细节缺失：

- 用户可以按表格记住每页条数，减少反复切换成本。
- 用户可以按表格隐藏低频列，提升一屏数据密度。
- 导出只导出当前可见列，避免“屏幕看到一套、Excel 又是一套”。
- 行操作区保持最小宽度和横向滚动，避免按钮挤压、换行、遮挡。
- 企业表格的偏好 key 增加页面标题兜底，减少不同表格设置串扰。

## 修改范围

- `components/DataTable.tsx`
  - 增加 `pageSizeOptions`。
  - 增加列显示控制。
  - 增加每页条数本地记忆。
  - 搜索、分页、导出与可见列保持一致。

- `components/ui/EnterpriseDataGrid.tsx`
  - 增加 `defaultVisible`、`preferenceKey`。
  - 增加列显示控制。
  - 增加本地分页条数记忆。
  - 状态列继续复用统一 `StatusBadge` 语义。

- `components/ui/tablePreferences.ts`
  - 新增轻量偏好读写工具。
  - 只封装 localStorage 安全读写，不引入状态管理库。

- `components/ui/dataTableAdapter.ts`
  - 支持向企业表格传递默认列可见性。

## 反幻觉校准

联网复核后，本轮方向与成熟 ERP / 企业软件反馈一致：

- Gartner Peer Insights 对 Cloud ERP 的 2026 经验教训强调业务需求、数据治理、分阶段实施和减少后续升级复杂度。
- NN/g 的企业表格任务模型强调表格必须支持查找、比较、编辑单行和批量操作。
- 企业数据表 UX 资料普遍建议提供列显示控制、冻结关键列、横向滚动和视图偏好。
- 近期 ERP 可用性讨论仍反复指向：系统复杂、录入成本高、移动/触摸体验弱、报表和数据对账不透明。

因此本轮没有走“堆新功能”路线，而是把高频表格的可读性、可控性和稳定性往商业 ERP 的工作台体验靠拢。
