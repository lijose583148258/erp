## 2. 核心需求分析

### 2.1 业务需求

#### A. 回款追踪（核心中的核心）

**为什么回款追踪是核心？**
- 中越美贸易跨国交易，付款周期长（30-90天）
- 汇率波动风险高
- 客户分散在三国，追踪困难
- 需要自动预警逾期客户

**回款追踪必须实现：**
1. **实时回款看板**
   - 今日/本周/本月回款金额
   - 逾期未付订单列表（按金额、时间排序）
   - 回款率趋势图
   - 客户回款信用评分

2. **多公司名称关联**
   ```
   公司A：
   - 中文名：深圳市某某贸易有限公司
   - 越南文名：Công ty TNHH Thương mại XX Thâm Quyến
   - 英文名：Shenzhen XX Trading Co., Ltd.
   ```

3. **自动催收工作流**
   - 逾期3天：系统自动发邮件提醒销售员
   - 逾期7天：自动发短信给客户
   - 逾期15天：自动标记为高风险，暂停新订单
   - 逾期30天：推送给法务部门

4. **回款预测AI**
   - 根据历史数据预测未来30天回款金额
   - 识别高风险客户（延迟付款倾向）

#### B. 三国财务报表

**越南财务报表（VAS - Vietnamese Accounting Standards）**
- 资产负债表（Bảng cân đối kế toán）
- 损益表（Báo cáo kết quả hoạt động kinh doanh）
- 现金流量表（Báo cáo lưu chuyển tiền tệ）
- 必须符合越南税务局要求

**中国财务报表（CAS - Chinese Accounting Standards）**
- 资产负债表
- 利润表
- 现金流量表
- 符合中国税务局要求

**美国财务报表（US GAAP）**
- Balance Sheet
- Income Statement
- Cash Flow Statement
- 符合SEC和IRS要求

**关键要点：**
- 三国会计科目映射表
- 自动货币转换（VND ↔ CNY ↔ USD）
- 实时汇率API集成
- 导出Excel/PDF格式

#### C. 工厂生产管理

**必须有的模块：**
1. **BOM物料清单**
   - 产品 → 原材料清单
   - 多级BOM支持
   - 替代料管理

2. **生产工单**
   - MO（Manufacturing Order）管理
   - 工序管理
   - 进度追踪
   - 质检节点

3. **库存管理**
   - 原材料库存
   - 成品库存
   - 在制品（WIP）
   - 最低库存预警
   - 批次管理

4. **质检管理**
   - IQC（来料检验）
   - IPQC（制程检验）
   - FQC（成品检验）
   - OQC（出货检验）

5. **车间看板**
   - 实时生产进度
   - 设备状态
   - 良品率统计

## 3. 技术架构升级方案

### 3.1 数据库迁移：SQLite → PostgreSQL

#### 为什么必须升级？

| 对比项 | SQLite（当前） | PostgreSQL（目标） |
|--------|----------------|-------------------|
| 并发写入 | ❌ 单用户写入 | ✅ 支持1000+并发 |
| 云端部署 | ❌ 文件锁定问题 | ✅ 原生支持 |
| 数据量 | ⚠️ <100GB | ✅ TB级 |
| 全文搜索 | ❌ 需要插件 | ✅ 原生支持 |
| 空间数据 | ❌ 不支持 | ✅ PostGIS |
| JSONB | ❌ JSON字符串 | ✅ 原生JSONB |

#### 迁移步骤

**1. 安装PostgreSQL**
```bash
# Ubuntu/Debian
sudo apt-get install postgresql postgresql-contrib

# macOS
brew install postgresql

# Windows
# 下载安装包：https://www.postgresql.org/download/windows/
```

**2. 修改Prisma Schema**
```prisma
// 将 provider 从 "sqlite" 改为 "postgresql"
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

**3. 更新环境变量**
```env
# .env
DATABASE_URL="postgresql://username:password@localhost:5432/ailaohua_erp"
```

**4. 数据迁移命令**
```bash
# 创建新的PostgreSQL迁移
npx prisma migrate dev --name init_postgresql

# 从SQLite导出数据
sqlite3 dev.db .dump > data_backup.sql

# 转换SQL语法（SQLite → PostgreSQL）
# 使用工具：https://github.com/coleifer/sqlite-web
# 或手动调整AUTO_INCREMENT → SERIAL等

# 导入PostgreSQL
psql -U username -d ailaohua_erp -f data_converted.sql
```

**5. 验证迁移**
```bash
# 运行测试
npm run test

# 检查数据完整性
npx prisma studio
```

**1. 财务Controller**
```typescript
// backend/src/controllers/finance.controller.ts

import { Request, Response } from 'express';
import { prisma } from '../config/database';

export class FinanceController {
  // 应收账款列表
  async getAccountReceivables(req: Request, res: Response) {
    const { status, customerId, overdue } = req.query;
    
    const where: any = {};
    if (status) where.status = status;
    if (customerId) where.customerId = parseInt(customerId as string);
    if (overdue === 'true') where.overdueDays = { gt: 0 };
```

```typescript
  async getRate(from: string, to: string): Promise<number> {
    // 先查数据库缓存（当天的汇率）
    const today = new Date();
    today.setHours(0, 0, 0, 0);
    
    const cached = await prisma.exchangeRate.findFirst({
      where: {
        fromCurrency: from,
        toCurrency: to,
        date: { gte: today },
      },
    });
    
    if (cached) return cached.rate;
    
    // 调用API获取最新汇率
    const response = await axios.get(
      `https://api.exchangerate-api.com/v4/latest/${from}`
    );
    
    const rate = response.data.rates[to];
    
    // 保存到数据库
    await prisma.exchangeRate.create({
      data: {
        fromCurrency: from,
        toCurrency: to,
        rate,
        source: 'exchangerate-api.com',
      },
    });
    
    return rate;
  }
  
  // 批量转换
  async convertAmount(amount: number, from: string, to: string): Promise<number> {
    if (from === to) return amount;
    
    const rate = await this.getRate(from, to);
    return amount * rate;
  }
  
  // 获取三国汇率表
  async getMultiCurrencyRates() {
    const currencies = ['CNY', 'VND', 'USD'];
    const rates: any = {};
    
    for (const from of currencies) {
      rates[from] = {};
      for (const to of currencies) {
        if (from !== to) {
          rates[from][to] = await this.getRate(from, to);
        }
      }
    }
    
    return rates;
  }
```

```typescript
        pass: process.env.SMTP_PASS,

  async runDailyCheck() {
    console.log('[AutoCollection] 开始每日回款检查...');
    
    // 查询所有未付订单
    const receivables = await prisma.accountReceivable.findMany({
      where: {
        status: { in: ['pending', 'partial'] },
      },
      include: {
        customer: true,
        order: true,
      },
    });
    
    for (const ar of receivables) {
      const overdueDays = this.calculateOverdueDays(ar.dueDate);
      
      // 更新逾期天数
      await prisma.accountReceivable.update({
        where: { id: ar.id },
        data: { overdueDays },
      });

      await this.executeAction(ar, overdueDays);
    }

  private calculateOverdueDays(dueDate: Date): number {
    const today = new Date();
```

```typescript
    const predictions = [];
    for (let i = 1; i <= 30; i++) {
      const predicted = average + (trend * i);
      predictions.push({
        date: new Date(Date.now() + i * 24 * 60 * 60 * 1000),
        amount: Math.max(0, predicted),
      });
    }
    
    return predictions;
  }
  
  // 识别高风险客户
  async identifyRiskyCustomers() {
    const customers = await prisma.customer.findMany({
      include: {
        orders: {
          include: {
            paymentRecords: true,
          },
        },
      },
    });
    
    const risky = customers.filter(customer => {
      // 计算延迟付款率
      const totalOrders = customer.orders.length;
      const latePayments = customer.orders.filter(order => {
        // 检查是否有延迟付款
        return order.paymentRecords.some(payment => {
          return payment.date > order.createdAt; // 简化逻辑
        });
      }).length;
      
      const lateRate = latePayments / totalOrders;
      return lateRate > 0.3; // 30%以上延迟率
    });
    
    return risky;
  }
}
```

#### A. 回款预测算法

```typescript
// 使用简单移动平均 + 趋势分析
export class CollectionPrediction {
  async predictNext30Days(customerId?: number): Promise<Prediction[]> {
    // 获取过去90天的回款数据
    const history = await this.getHistoricalData(90, customerId);
    
    // 计算移动平均
    const ma7 = this.movingAverage(history, 7);   // 7天平均
    const ma30 = this.movingAverage(history, 30); // 30天平均
    
    // 计算趋势
    const trend = this.calculateTrend(history);
    
    // 生成预测
    const predictions: Prediction[] = [];
    for (let i = 1; i <= 30; i++) {
      const baseAmount = ma30[ma30.length - 1];
      const trendAdjustment = trend * i;
      const seasonalFactor = this.getSeasonalFactor(i);
      
      predictions.push({
        date: addDays(new Date(), i),
        predictedAmount: Math.max(0, baseAmount + trendAdjustment * seasonalFactor),
        confidence: this.calculateConfidence(i),
      });
    }
    
    return predictions;
  }
  
  private calculateTrend(data: number[]): number {
    // 简单线性回归
    const n = data.length;
    const sumX = (n * (n + 1)) / 2;
    const sumY = data.reduce((a, b) => a + b, 0);
    const sumXY = data.reduce((sum, y, i) => sum + (i + 1) * y, 0);
    const sumX2 = (n * (n + 1) * (2 * n + 1)) / 6;
    
    return (n * sumXY - sumX * sumY) / (n * sumX2 - sumX * sumX);
  }
}
```

```typescript
export class RiskAssessment {
  async assessCustomerRisk(customerId: number): Promise<RiskScore> {
    const customer = await prisma.customer.findUnique({
      where: { id: customerId },
      include: {
        orders: {
          include: {
            paymentRecords: true,
          },
        },
      },
    });
    
    // 计算多个风险指标
    const indicators = {
      paymentDelayRate: this.calculateDelayRate(customer.orders),
      averageDelayDays: this.calculateAverageDelay(customer.orders),
      overdueAmount: customer.overdueAmount,
      creditUtilization: customer.overdueAmount / (customer.creditLimit || 1),
      orderFrequency: this.calculateOrderFrequency(customer.orders),
    };
    
    // 综合评分（0-100）
    let score = 100;
    score -= indicators.paymentDelayRate * 50;  // 延迟率权重50%
    score -= Math.min(30, indicators.averageDelayDays); // 平均延迟天数权重30%
    score -= indicators.creditUtilization * 20; // 信用额度使用率权重20%
    
    // 风险等级
    let level: string;
    if (score >= 80) level = 'low';
    else if (score >= 60) level = 'medium';
    else if (score >= 40) level = 'high';
    else level = 'critical';
    
    return { score, level, indicators };
  }
}
```

### 8.3 PWA离线支持

**service-worker.js增强**
```javascript
// sw.js

const CACHE_VERSION = 'v1.0.0';
const CACHE_NAME = `ailaohua-${CACHE_VERSION}`;

const STATIC_ASSETS = [
  '/',
  '/index.html',
  '/manifest.json',
  '/icon.svg',
  // ... 其他静态资源
];

// 安装Service Worker
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      return cache.addAll(STATIC_ASSETS);
    })
  );
  self.skipWaiting();
});

// 激活Service Worker
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((cacheNames) => {
      return Promise.all(
        cacheNames
          .filter((name) => name !== CACHE_NAME)
          .map((name) => caches.delete(name))
      );
    })
  );
  self.clients.claim();
});

// 拦截请求
self.addEventListener('fetch', (event) => {
  const { request } = event;
  const url = new URL(request.url);

  // API请求：网络优先，失败时返回离线数据
  if (url.pathname.startsWith('/api/')) {
    event.respondWith(
      fetch(request)
        .then((response) => {
          // 缓存成功的响应
          const clonedResponse = response.clone();
          caches.open(CACHE_NAME).then((cache) => {
            cache.put(request, clonedResponse);
          });
          return response;
        })
        .catch(() => {
          // 网络失败，返回缓存
          return caches.match(request);
        })
    );
  }
  // 静态资源：缓存优先
  else {
    event.respondWith(
      caches.match(request).then((cachedResponse) => {
        return cachedResponse || fetch(request);
      })
    );
  }
});
```

**IndexedDB数据同步**
```typescript
// utils/offlineSync.ts

import { openDB } from 'idb';

const DB_NAME = 'ailaohua_offline';
const STORE_NAME = 'pending_changes';

export class OfflineSync {
  private db: any;

  async init() {
    this.db = await openDB(DB_NAME, 1, {
      upgrade(db) {
        db.createObjectStore(STORE_NAME, { keyPath: 'id', autoIncrement: true });
      },
    });
  }

  // 保存离线变更
  async saveChange(change: any) {
    await this.db.add(STORE_NAME, {
      ...change,
      timestamp: Date.now(),
      synced: false,
    });
  }

  // 同步所有未同步的变更
  async syncAll() {
    const changes = await this.db.getAll(STORE_NAME);
    const unsynced = changes.filter((c: any) => !c.synced);

    for (const change of unsynced) {
      try {
        await this.syncChange(change);
        await this.db.put(STORE_NAME, { ...change, synced: true });
      } catch (error) {
        console.error('同步失败:', change, error);
      }
    }
  }

  private async syncChange(change: any) {
    const response = await fetch('/api/sync', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(change),
    });

    if (!response.ok) {
      throw new Error('Sync failed');
    }
  }
}

// 监听网络状态
window.addEventListener('online', () => {
  const sync = new OfflineSync();
  sync.init().then(() => sync.syncAll());
});
```
