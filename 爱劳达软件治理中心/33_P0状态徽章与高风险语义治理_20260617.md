# P0 状态徽章与高风险语义治理

日期：2026-06-17

## 本次范围

本次继续执行 `31_跨国贸易ERP企业版进一步优化蓝图_20260617.md` 的 P0 公共可用性底座。

只治理状态显示口径，不改业务状态机、不改后端接口、不改数据库字段。

## 已完成

1. 状态标签统一
   - 新增 `components/ui/statusBadgeLogic.ts`。
   - 将常见状态码统一映射为中文业务标签，例如 `pending -> 待处理`、`overdue -> 已逾期`、`payment_submitted -> 待财务核验`。
   - `DataTable` 和 `EnterpriseDataGrid` 的状态列现在共用同一套标签来源。

2. 高风险状态语义
   - 将 `critical`、`overdue`、`expired`、`missed`、`rejected`、`terminated`、`exception`、`fail`、`missing`、`short`、`unpaid` 标记为高风险状态。
   - `StatusBadge` 对高风险状态增加更强的 ring 语义。
   - 徽章输出 `data-risk="high"`，后续可用于审计或样式回归。

3. 组件职责拆分
   - `StatusBadge.tsx` 只负责渲染组件。
   - 状态颜色、标签、高风险判断拆到 `statusBadgeLogic.ts`。
   - 避免 Fast Refresh 对“组件文件导出非组件函数”的警告。

4. 旧引用收口
   - 生产、调账、回款中心里对 `getStatusBorderBadgeClassName` 的引用已改到 `statusBadgeLogic.ts`。
