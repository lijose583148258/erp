# 49_P3采购工作台低复杂度拆薄与三语文案修复_20260619

## 范围

- `pages/Procurement.tsx`
- `pages/procurement/ProcurementDerived.ts`
- `pages/procurement/ProcurementInputGuide.tsx`
- `pages/procurement/useProcurementUnsavedFormGuards.ts`
- `pages/procurement/procurementForms.ts`
- `pages/procurement/procurementDeskCopy.ts`
- `pages/procurement/ProcurementDeskNavigator.tsx`

## 问题

1. `pages/Procurement.tsx` 被全仓审计列为 P2 超大文件，原文件 625 行。
2. 采购主页面同时承担统计、筛选、供应商显示名、状态文案、顶部说明、未保存保护，维护边界不够清楚。
3. `procurementForms.ts` 中默认单位和校验提示存在乱码，用户填错表单时无法理解错误原因。
4. `procurementDeskCopy.ts` 中中文和越南语文案存在乱码，跨国语言使用体验不可靠。

## 处理原则

- 不改采购 API，不改订单/收货状态机。
- 只抽无副作用计算、顶部说明和未保存保护。
- 表单校验函数名和返回结构保持不变。
- 三语文案恢复为可读内容，避免继续堆复杂抽象。

## 已完成

- 新增 `ProcurementDerived.ts`：承接采购统计、收货可用计数、订单显示过滤、供应商搜索、供应商显示名、状态文案和日期格式。
- 新增 `ProcurementInputGuide.tsx`：承接采购页顶部流程说明。
- 新增 `useProcurementUnsavedFormGuards.ts`：承接供应商和采购订单的未保存保护。
- 重写 `procurementDeskCopy.ts`：恢复中英越采购导航和边界说明。
- 重写 `procurementForms.ts`：恢复默认单位、供应商/采购单/收货批次校验提示。
- `Procurement.tsx` 从 625 行降到 539 行，不再进入全仓 P2 超大文件清单。
