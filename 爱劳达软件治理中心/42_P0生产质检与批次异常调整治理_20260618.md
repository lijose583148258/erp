# 42_P0生产质检与批次异常调整治理_20260618

## 目标

补齐生产模块中“质检记录”和“批次异常调整”的 P0 可用性缺口：字段级错误、保存中状态、防重复提交。

本轮保持代码简洁，不新增复杂表单框架，不把批次异常调整扩展成完整 MES / QMS / CAPA 流程。

## 联网反幻觉校准

制造质量与库存调整资料的共同结论：

- 质量记录应能稳定记录缺陷、检查人和结果，并支持后续审计和问题闭环。
- 库存调整是高风险入口，应该留下审计轨迹，不能成为绕过正常入库、完工、领料的快捷通道。
- 用户真实负反馈集中在：质量数据分散、重复录入、调整原因不清、无法追踪是谁改了库存、调整后库存仍不可信。

因此，本轮只做最小而必要的 P0：错误贴近字段、保存时防重复提交、异常数量和原因必须清晰。

## 已执行改动

### 1. 质检记录

文件：

- `pages/ProductionWorkspaceV2.tsx`
- `pages/production/ProductionWorkOrderSection.tsx`

改动：

- 新增 `QualityFormErrors`。
- 缺陷率必须在 0 到 100 之间。
- 不合格记录必须填写质检人。
- 缺陷率和质检人使用字段级错误提示。
- 保存期间按钮显示“保存中...”并禁用，避免重复提交。
- 缺陷率只转换一次后提交给后端，减少重复数字转换。

### 2. 批次异常调整

文件：

- `pages/ProductionWorkspaceV2.tsx`
- `pages/production/ProductionBatchAdjustmentSection.tsx`

改动：

- 新增 `AdjustmentFormErrors`。
- 未选择批次时显示批次错误。
- 数量必须大于 0。
- 原因不能为空。
- 数量、原因使用字段级错误提示。
- 提交期间按钮显示“提交中...”并禁用。
- 切换异常模板时清除原因错误，避免旧错误干扰用户。
