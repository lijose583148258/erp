# 待拆分模块清单_2026-04-23

## 使用原则

这份清单用于后续降低维护成本，不代表马上全部拆。

拆分前必须满足：

| 条件 | 要求 |
| --- | --- |
| 当前闭环可跑 | 先确认相关 API / 浏览器 / 数据库链路是绿的 |
| 写集可控 | 每次只拆一个业务域或一组强相关文件 |
| 不改变业务行为 | 首包优先搬运、命名、分层，不顺手改业务规则 |
| 主控复验 | 拆分完成后由主控重跑构建、业务闭环、阶段链 |
| 禁乱码闸门 | 任意中文文案变化必须三步法 |
