# 根目录治理方案

## 目标

减少根目录混杂，降低后续维护时的查找成本和误操作风险。

## 当前分层

### 运行主线

- `backend`
- `components`
- `pages`
- `services`
- `src`
- `utils`
- `public`
- `dist`
- `logs`
- `backups`

### 治理与文档

- `爱劳达软件治理中心`
- `文档归档`
- `测试`

### 历史归档

- `历史归档/01_旧版本`
- `历史归档/02_打包产物`

- `测试/压力测试配置.ts` -> `测试/02_性能测试`

## 后续规则

- 根目录只保留当前运行必需文件和少量顶层说明
- 历史报告不再和当前治理文档混放
- 打包物不再停留在根目录
- 包文档统一放入治理中心的主线任务目录
