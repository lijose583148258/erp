## 关键文件

| 文件 | 说明 |
|------|------|
| `App.tsx` | 应用根组件，所有路由定义 |
| `index.tsx` | React 入口 |
| `types.ts` | 全局类型定义（10KB） |
| `constants.tsx` | 全局常量 |
| `vite.config.ts` | Vite 配置（唯一，无 .fixed 副本） |
| `tsconfig.json` | TypeScript 配置 |
| `.gitignore` | 版本控制排除规则 |
| `Dockerfile` + `docker-compose.yml` | 容器化部署 |
| `正式启动.bat` / `停止服务.bat` | Windows 启停脚本 |

## 零代理壳声明

截至 2026-04-15，`pages/` 下所有 `.tsx` 文件均为**直接实体**（非 re-export 壳）。唯一保留的转发层是 `pages/crm/useCRM.ts` → `useCRM.tsx`，因为 `CRM.tsx` 通过目录导入解析到 `.ts`。
